# vu-icons 图标字体化重构计划

## 目标

将 vu-icons 从 SVG 内联渲染方式重构为**字体图标 (iconfont)** 方案，确保 UniApp 导入后在微信小程序中正常显示。

## 现状分析

- `src/` 构建管线生成 SVG 内联组件（~1821 个）
- `dist/` 已有完整的字体图标实现（来自一个丢失的构建脚本）：
  - `dist/VuIcon.vue` — Vue3 基础组件（`<i>` 标签 + CSS 类）
  - `dist/VuIconUniApp.vue` — UniApp 基础组件（`<text>` 标签 + CSS 类）
  - `dist/font/vu-icons.woff2` — 85KB 字体文件
  - `dist/font/vu-icons.css` — @font-face + 图标类定义
  - `dist/vue3/*.vue` / `dist/uniapp/*.vue` — 薄包装组件

## 实施步骤

### Step 1: 安装依赖

```bash
npm install -D fantasticon
```

fantasticon 用于将 SVG 目录转换为 woff2 字体 + CSS + JSON。

### Step 2: 创建基础组件源文件

**新建 `src/base/VuIcon.vue`** — Vue3 基础组件（从现有 `dist/VuIcon.vue` 迁移）

**新建 `src/base/VuIconUniApp.vue`** — UniApp 基础组件（从现有 `dist/VuIconUniApp.vue` 迁移）

### Step 3: 创建字体构建脚本

**新建 `src/build-font.ts`** — 替代 `src/build-components.ts`

分 4 个阶段：
1. **字体生成** — 调用 fantasticon 从 `src/icons/optimized/` 生成 woff2 + CSS + JSON 到 `dist/font/`
2. **基础组件复制** — 将 `src/base/*.vue` 复制到 `dist/`
3. **包装组件生成** — 为每个图标生成薄包装组件到 `dist/vue3/` 和 `dist/uniapp/`
4. **入口文件生成** — 生成 index.js、index.esm.js、index.d.ts、icons.json、web-types.json

### Step 4: 更新构建配置

**修改 `package.json`** — 更新 scripts：
- `"build:font": "tsx src/build-font.ts"` 替代 `"build:components"`
- `"build": "gulp optimizeSvg && npm run build:font"`

**修改 `gulpfile.js`** — 简化为仅 SVG 优化，移除 build/copy 相关 task

### Step 5: 清理旧文件

**删除：**
- `src/build-components.ts`
- `src/components/Vue3IconTemplate.ts`
- `src/components/UniAppIconTemplate.ts`
- `src/components/vue3/*.vue`（1821 个 SVG 组件）
- `src/components/uniapp/*.vue`（1821 个 SVG 组件）
- `src/index.ts`、`src/index.d.ts`、`src/icons.json`、`src/web-types.json`
- `src/components/icon-font/`、`src/font/`、`fonts/`（空目录）

### Step 6: 更新验证脚本

**修改 `scripts/verify-build.ts`** — 检查字体文件存在、CSS 包含 @font-face、组件数量匹配等。

## 组件 API 保持不变

```vue
<!-- 使用方式不变 -->
<script setup>
import { VuUser, VuSearch } from 'vu-icons'           // Vue3
import { VuUser, VuSearch } from 'vu-icons/uniapp'     // UniApp
</script>

<template>
  <VuUser size="24" color="#333" :spin="false" />
</template>
```

Props：`size`、`color`、`className`、`spin` — 全部保持一致。

## 验证方式

1. 运行 `npm run build` 确认构建成功
2. 检查 `dist/font/vu-icons.woff2` 存在且 > 50KB
3. 检查 `dist/font/vu-icons.css` 包含 @font-face 和所有图标类
4. 检查 `dist/vue3/` 和 `dist/uniapp/` 组件数量与图标总数一致
5. 运行 `npm run test`（verify-build.ts）
6. 在 UniApp 项目中导入测试，确认微信小程序中图标正常显示
